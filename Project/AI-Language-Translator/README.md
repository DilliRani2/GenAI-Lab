# 🌐 AI Language Translator

An AI-powered language translation application built using Python, Hugging Face Transformers, and Gradio.

## ✨ Features

- Translates text between supported languages.
- Uses a pretrained multilingual translation model.
- Provides an interactive web interface using Gradio.
- Accepts user input and displays translated text.

## 🛠️ Technologies Used

- Python
- Hugging Face Transformers
- PyTorch
- Gradio

## 🚀 Installation and Usage

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd AI-Language-Translator
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python app.py
```

Open the local Gradio URL shown in the terminal.
